# Configuration

`migration.example.json` is a placeholder-only example for a future migration configuration.

Copy it outside version control or to an ignored local file, then replace only the `${...}` placeholders with approved resource identifiers. Do not place Discord tokens, bot secrets, webhook secrets, or other credentials in this file or in the repository.

Configuration identifies the intended source and destination. It does not grant migration authorization. Operational execution remains unavailable in Phase 0 and will require the separate HITL gates defined by the authoritative documents in later phases.
